# Pure Energy Germany Challenge

This project contains a single-page React application for the Pure Energy Germany sales challenge.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The static site will be output to the `dist` directory. Upload the contents of that folder to your web host (e.g. an IONOS subdomain).

## Testing

```bash
npm test
```

Runs the Vitest unit tests.
